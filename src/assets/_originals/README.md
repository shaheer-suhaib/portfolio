# Original source images

The site ships the WebP versions in `public/images/`. These are the full-size
originals, kept for re-export. Nothing imports them, so Vite does not bundle
them and they are not deployed.

| File | Used for |
|---|---|
| `face.png` | studio portrait on a white ground — source for the hero cutout |
| `face-cutout.png` | white background knocked out — source for `face-cutout.webp` |
| `side_img.png` | source for `side_img.webp` (About) |
