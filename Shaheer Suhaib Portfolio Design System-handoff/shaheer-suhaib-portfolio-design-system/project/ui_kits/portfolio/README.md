# Portfolio UI Kit

A high-fidelity HTML/JSX recreation of Shaheer Suhaib's portfolio website.

## Structure

- `index.html` — Full interactive click-through prototype
- `Nav.jsx` — Sticky navigation bar with active states + mobile menu
- `Hero.jsx` — Hero section with profile photo, animated headline, CTAs
- `About.jsx` — About section with bio, skill pills, stats
- `Experience.jsx` — Skills & Experience two-column layout with cards
- `Contact.jsx` — Contact form + contact details
- `Footer.jsx` — Footer with links + copyright

## Design Width

Designed at 1440px desktop. Fully responsive down to 375px mobile.

## Font Loading

All components expect `colors_and_type.css` (or equivalent Google Fonts import) to be loaded in the host document.
